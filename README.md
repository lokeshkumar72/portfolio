# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website! This portfolio showcases my **skills, projects, education, internships, and experience** as a Full Stack Developer.

The website is designed with a clean, modern, and responsive interface to provide recruiters and visitors with an overview of my technical background and development work.

## 💻 Getting Started

To run this project locally:

### 1. Clone the repository

```bash
git clone https://github.com/lokeshkumar72/portfolio.git
```

### 2. Navigate to the project

```bash
cd portfolio
```

### 3. Run the project

Since this is a static website, you can open `index.html` directly in your browser.

For a better development experience, you can use **VS Code Live Server**.
